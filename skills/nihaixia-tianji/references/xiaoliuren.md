# 小六壬：日常小事快断

## 适用场景

日常心血来潮的小纠结——今天出门办事顺不顺、下午去面试行不行、这个约会该不该去。小事快速参考，不用于重大人生选择。

## 需要的信息

- 占问事项（你想问的具体小事）
- 时间信息（二选一）：
  - **模式 A**：手动提供农历月、农历日、时辰
  - **模式 B**：只说"基于现在的时间帮我算"，Agent 自动换算

## 算法

### 六宫顺序（固定循环）

```
大安(0) → 留连(1) → 速喜(2) → 赤口(3) → 小吉(4) → 空亡(5) → 大安(6) → ...
```

### 起课公式

```
结果 = (农历月 + 农历日 + 时辰序号 - 3) % 6
```

余数映射：

| 余数 | 六神 | 吉凶 | 关键词 | 大白话 |
|------|------|------|--------|--------|
| 0 | 大安 | ✅ 吉 | 稳定、平安 | 事情稳稳的，可以做 |
| 1 | 留连 | ➖ 平 | 拖延、等待 | 会拖，别急，等一等 |
| 2 | 速喜 | ✅ 吉 | 喜事、快速 | 好消息快来，速度快 |
| 3 | 赤口 | ❌ 凶 | 口舌、是非 | 小心吵架，态度放软 |
| 4 | 小吉 | ✅ 吉 | 小成、顺利 | 小事顺利，适合做 |
| 5 | 空亡 | ❌ 凶 | 落空、无果 | 白跑一趟，改天再去 |

### 时辰序号

| 时辰 | 时间段 | 序号 |
|------|--------|------|
| 子 | 23:00-01:00 | 1 |
| 丑 | 01:00-03:00 | 2 |
| 寅 | 03:00-05:00 | 3 |
| 卯 | 05:00-07:00 | 4 |
| 辰 | 07:00-09:00 | 5 |
| 巳 | 09:00-11:00 | 6 |
| 午 | 11:00-13:00 | 7 |
| 未 | 13:00-15:00 | 8 |
| 申 | 15:00-17:00 | 9 |
| 酉 | 17:00-19:00 | 10 |
| 戌 | 19:00-21:00 | 11 |
| 亥 | 21:00-23:00 | 12 |

### 验证示例

```
农历三月初五午时：
(3 + 5 + 7 - 3) % 6 = 12 % 6 = 0 → 大安 ✓

农历八月十二申时：
(8 + 12 + 9 - 3) % 6 = 26 % 6 = 2 → 速喜 ✓
```

## 执行流程

### 模式 A：手动时间

1. 用户提供占问事项 + 农历月日时
2. Agent 按公式计算，展示完整过程
3. 输出卦象解读 + 行动建议

### 模式 B：当前时间

1. 用户只说"基于现在的时间帮我算一下……"
2. Agent 获取当前公历时间和时区
3. 换算为农历月、农历日、时辰
4. 按公式计算，展示完整过程
5. 输出卦象解读 + 行动建议

**重要约束**：
- 默认使用用户当前所在地/设备时区
- 如无法可靠完成公历转农历，必须调用可用日历或联网工具查询
- 无工具时追问用户，不得凭记忆换算农历日期
- 如果 Agent 无法获取当前日期/时区，必须追问，不得编造

## 输出格式

```
一、时间确认
   时间来源：[用户手动提供 / 当前对话时间]
   公历时间：YYYY-MM-DD HH:mm
   换算农历：农历X月X日
   当前时辰：X时（序号=N）

二、起课计算
   公式：(M + D + H - 3) % 6
   代入：(X + X + X - 3) % 6 = N
   最终落宫：[六神名]

三、卦象解读
   [大白话解释，重点说吉凶/成败/快慢]

四、关键提示
   [1-2 条具体建议]

五、避坑提醒
   [如有警示]

六、边界声明
```

## 边界

- 仅用于日常小事（出行/约见/办事/交易/约会）
- 不涉及重大决策（投资/婚姻/医疗等）
- 结果是"参考信号"，不是"命运判决"
- 最终决定权在用户
- 解读用大白话，不堆砌专业术语
