# 紫微斗数核心框架与格局速查

> **定位说明**：本文件是配合本仓 [`01-天机道.md`](../01-天机道.md) 与 [`天机道笔记.md`](./天机道笔记.md) 使用的学习速查手册（非明代古籍逐字原文）。仅用于梳理倪海厦《天纪》紫微斗数的基础术语、看盘顺序与常见格局，仅供传统文化学习与自我复盘参考。

## 一、倪海厦《天纪》看盘的 4 条核心原则

1. **三合为用，大道至简**：以本命宫为轴，重点看**三方四正**（命宫 + 财帛宫 + 官禄宫 + 迁移宫）的星曜会照与生年四化；主张稳扎稳打看主星、辅煞与大限流年，不主张套用繁复的飞星飞化。
2. **以果决行，谈果不谈因**：看盘的意义在于提前看清趋势与短板（知果），从而调整现实中的职业选择、合作方式与处事节奏（决行），而不是拿命盘当宿命论借口。
3. **人事 + 地理 > 先天定数**：先天命盘只占三分之一，居住/工作环境（地脉道）与后天修养行动（人间道）合起来占三分之二；命盘有破绽，靠环境与人为决策可以大幅化解。
4. **关于六亲判断的明确边界**：倪师在《天纪》课堂中明确指出，**紫微斗数在判断六亲（父母、兄弟、子女等）方面本身相对偏弱**，不如专核六亲的术数精细；真正强项在于结合地理与人事看个人格局与运势起伏。因此涉及六亲的解读一律只作倾向参考，切忌生搬硬套。

## 二、十二宫位与三方四正

看盘先立「命宫」，再看与它成三角形（三方）和对角线（四正）联动的宫位：

| 宫位 | 主要观察范围 | 常见联动关系 |
| --- | --- | --- |
| **命宫** | 性格底色、天赋倾向、抗压方式与人生主轴 | 与财帛、官禄、迁移组成「命宫三方四正」 |
| **兄弟宫** | 手足关系、平辈合作与短期现金周转 | 对宫为仆役（交友）宫 |
| **夫妻宫** | 伴侣气质、亲密关系互动模式与婚姻课题 | 对宫为官禄宫（事业与家庭常相互牵动） |
| **子女宫** | 子女缘分、创作产出与合伙下属 | 对宫为田宅宫 |
| **财帛宫** | 赚钱方式、财务观念与资金流向 | 与命宫、官禄宫三合 |
| **疾厄宫** | 体质强弱、易劳损部位与健康作息提醒（**不替代医学诊断**） | 对宫为父母宫 |
| **迁移宫** | 外出发展、社交第一印象与变动环境中的机会 | 与命宫直冲对照 |
| **交友宫（仆役宫）** | 同事、朋友、客户群与外部助力 | 对宫为兄弟宫 |
| **官禄宫（事业宫）** | 工作形态、适合行业、管理风格与事业平台 | 与命宫、财帛宫三合 |
| **田宅宫** | 居住环境、不动产积累与家庭底盘 | 对应《地脉道》阳宅观察重点 |
| **福德宫** | 精神世界、消费习惯、焦虑来源与晚年心境 | 对宫为财帛宫（心态影响财运） |
| **父母宫** | 长辈缘分、上司关系与早年家庭氛围 | 属于六亲宫位，仅作倾向参考 |

> **身宫**：寄于命、迁、财、官、夫、福六宫之一，通常用来看**中年之后重心转向哪里**以及晚景归宿。

## 三、十四主星速查

### 北斗星系（偏主动、开创、外放）

| 主星 | 核心气质 | 喜见 | 忌见 / 需防 |
| --- | --- | --- | --- |
| **紫微** | 帝座、统筹、自尊、重格局 | 左辅、右弼、文昌、文曲、天魁、天钺 | 孤君无辅（易独断孤高）、空劫 |
| **贪狼** | 欲望、人脉、才艺、机变、桃花 | 火星、铃星（火贪/铃贪爆发）、化禄 | 过旺无制（分心贪多、感情纠纷） |
| **巨门** | 思辨、口才、研究、暗星（是非/深挖） | 化禄、化权、太阳庙旺解暗 | 化忌、擎羊陀罗（易犯口舌猜忌） |
| **廉贞** | 秩序、公关、政治手腕、次桃花 | 化禄、天府、文昌文曲制化 | 化忌加煞（情绪激烈、官非纠纷） |
| **武曲** | 刚毅、执行、实业、正财星 | 禄存、化禄、化权、天府 | 孤克寡宿、化忌（现金流吃紧、过刚易折） |
| **破军** | 破旧立新、先锋、大幅变动 | 化禄、化权、紫微同宫制化 | 煞星齐聚（耗损大、反复折腾） |

### 南斗星系（偏守成、谋划、内敛）

| 主星 | 核心气质 | 喜见 | 忌见 / 需防 |
| --- | --- | --- | --- |
| **天府** | 财库、稳健、包容、守成 | 禄存、紫微、左右辅弼 | 空劫（空库、名大于实） |
| **天机** | 思考、策划、敏捷、变动 | 化科、化权、文昌文曲 | 化忌（思虑过度、犹豫内耗） |
| **天相** | 印星、协调、辅佐、重体面 | 左右辅弼、紫微、武曲 | 刑忌夹印（进退两难、替人背锅） |
| **天同** | 福星、温和、享乐、重感受 | 化禄、适度激发动力 | 过于安逸缺乏推动力 |
| **天梁** | 荫星、长者风范、原则、逢凶化吉 | 化科、太阳、文昌文曲 | 过于说教孤高、替人操心 |
| **七杀** | 将星、果决、独立、开拓 | 紫微制化、三方吉星 | 煞星过重（孤独波折、易冲动受伤） |

### 中天二星（日月：主象与节律）

| 主星 | 核心气质 | 关键看点 |
| --- | --- | --- |
| **太阳** | 博爱、发光、名声、付出、主父/夫 | 极看**庙旺落陷**（寅至午宫旺，戌至子宫陷，落陷则辛劳、宜借光或走技术幕后） |
| **太阴** | 细腻、储蓄、内敛、田宅、主母/妻 | 同样极看**庙旺落陷**（申至子宫旺，寅至午宫陷；旺则温和聚财，陷则心思多虑） |

## 四、辅星、煞星与四化

- **六吉星（助力）**：
  - `左辅 / 右弼`（团队助力、平辈帮衬）
  - `文昌 / 文曲`（学习考试、文书表达、审美才华）
  - `天魁 / 天钺`（长辈/贵人提携、关键机会）
- **六煞星（阻力与磨砺）**：
  - `擎羊 / 陀罗`（冲撞急躁 / 拖延纠缠）
  - `火星 / 铃星`（突发猛烈 / 暗中闷烧）
  - `地空 / 地劫`（损耗落空、不按常理出牌，但利哲学/创意/玄学思考）
- **生年四化（命盘的四个高亮标记）**：
  - **化禄**：资源、人缘、顺畅变现的入口
  - **化权**：掌控欲、专业权威、主动突破的抓手
  - **化科**：名声、口碑、贵人解厄与学习力
  - **化忌**：执念、短板、人生最需要直面和下功夫修补的功课（不是单纯的「倒霉」，修通之后往往变成专业护城河）

## 五、常见经典格局速查

| 格局名称 | 构成特征 | 核心倾向 | 现实建议 |
| --- | --- | --- | --- |
| **杀破狼格** | 七杀、破军、贪狼会聚命宫三方四正 | 一生变动多、不甘平淡，开创力强 | 适合创业、业务拓展、变革型岗位；年轻时防冲动冒进，先练稳底盘 |
| **机月同梁格** | 天机、太阴、天同、天梁会聚命宫三方四正 | 思虑细致、偏稳健累积，重专业与秩序 | 适合大平台、研究、医疗、教育、行政、专业顾问，不宜高杠杆孤注一掷 |
| **紫府同宫 / 紫府朝垣** | 紫微与天府同宫（寅申）或三方会照 | 稳重有大局观，兼顾统筹与守成 | 适合管理、平台整合；仍需看是否有辅弼相助，避免眼高手低 |
| **府相朝垣格** | 天府、天相在三方会照命宫 | 人际协调力强、重信誉、衣食安稳 | 适合统筹协同、运营、顾问角色，忌空劫与刑忌夹破 |
| **双禄朝垣格** | 化禄与禄存会聚命宫三方四正 | 资源与现金流机会较好 | 忌空劫冲破变成「虚名过路财」，需做好资产沉淀 |
| **七杀朝斗格** | 七杀居子午或寅申，对宫紫微天府相照 | 独立扛事、越挫越勇、大器晚成 | 适合独当一面的硬仗岗位，早年磨砺后中年发力 |
| **火贪 / 铃贪格** | 贪狼遇火星或铃星同宫/会照（无重煞冲破） | 爆发力强、机会来得突然 | 抓住窗口期后及时收口落袋，切忌顺风时过度扩张 |
