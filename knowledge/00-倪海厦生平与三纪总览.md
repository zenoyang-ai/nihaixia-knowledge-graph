# 倪海厦生平与三纪总览

第一次接触倪海厦老师的体系，最容易搞混的是「天纪、人纪、地纪」各自讲什么、彼此怎么连起来，以及应该从哪一份资料下手。这一页把三纪全景、生平师承和本仓库的文件位置放在一张图里对照。

## 一、三纪全景：天纪 · 人纪 · 地纪

倪海厦老师把毕生想传承的学问划为「天地人」三纪，核心是一句话：**上知天文，下知地理，中知人事（医道）**。

| 体系 | 核心主题 | 解决什么问题 | 传世状态 | 本仓库对应资料 |
| --- | --- | --- | --- | --- |
| **天纪** | 易经、紫微斗数、阳宅风水、人间处世 | 看清局势与趋势，「以果决行」，借环境与人事主动趋吉避凶 | 1994 年录成 24 集课程及配套讲义，完整传世 | [`03-天纪学习资料/`](./03-天纪学习资料/README.md) · [`skills/nihaixia-tianji/`](../skills/nihaixia-tianji/README.md) |
| **人纪** | 针灸、黄帝内经、神农本草经、伤寒论、金匮要略 | 治病救人，把经方和针灸的底层逻辑讲透，让后学能看懂古经 | 2004–2005 年授课出版五大经典全套课程 | [`04-人纪学习资料/`](./04-人纪学习资料/README.md) · [`05-公开讲座与访谈/`](./05-公开讲座与访谈/README.md) |

### 三纪之间的关系

1. **天纪与人纪同源**：两者都从《易经》的阴阳消长、五行生克和象数思维出发。人纪落在人体的气血脏腑与经方辨证，天纪落在时运、空间环境与人事进退。
2. **「人大于天」的改命观**：倪师反复强调，先天命盘只是三分之一，**地理环境 + 后天人事努力大于先天定数**；算命不是为了认命，而是「以果决行」——提前看到风险，用现实行动和环境选择避开它。
3. **关于《地纪》**：因为倪师于 2012 年辞世，《地纪》并没有正式出版的成书。想了解他的地理观，目前最扎实的一手入口仍是《天纪》中的《地脉道》以及《梁冬对话倪海厦》里谈及山水气候与人体的片段。

## 二、生平与师承脉络

### 师承背景

| 方向 | 师承渊源 | 说明 |
| --- | --- | --- |
| **针灸** | 周左宇医师、徐济民医师 | 1970 年代末在台湾拜师习针，打下十二经络与针刺补泻功底 |
| **经方** | 姜佐景一脉（师承民国经方名家曹颖甫） | 承接经方派重《伤寒》《金匮》、重理法方药一贯的思路 |
| **易理与术数** | 传统三合派紫微、象数易经与阳宅九宫 | 主张「大道至简」，反对繁琐堆砌，强调天人地三才互相印证 |

### 主要经历

| 时间 | 关键节点 |
| --- | --- |
| 1954 | 生于台北，祖籍浙江瑞安 |
| 1970 年代 | 少年时研读《医宗金鉴》为家人调理痛经，立志习医；随后拜师学习针灸与经方 |
| 1978–1979 | 服役期间行医积累临床经验；退伍后以「梵宇龙」之名在台湾研习与教授命理地理 |
| 1980 年代 | 移居美国；1988 年前后在台北开班讲授紫微斗数与阳宅地理 |
| 1994 | 完成《天纪》系列讲授录制（共 24 集）及《天机道》《地脉道》《人间道》配套讲义 |
| 1995 | 在美国佛罗里达州创办汉唐中医学院 |
| 2000–2003 | 曾任美国佛州卫生署中医委员会委员、佛州针灸委员会委员等职 |
| 2004–2005 | 开讲并出版《人纪》五大经典完整教学课程 |
| 2009 | 赴广西南宁、桂林及北京等地开展《扶阳论坛》《仲景心法》《经方的妙用》公开讲座，并与梁冬录播 7 讲《国学堂》深度对话 |
| 2012 | 1 月 31 日辞世于台北，享年 59 岁，《地纪》成为未竟之业 |
